# Registro de prompts

Por solicitação do usuário, registre cada novo prompt de trabalho em `prompts.md`, preservando os registros anteriores. Informe a data, o texto do prompt, a fonte/ferramenta, o modelo utilizado, o nível de effort configurado e o uso dado à resposta. Atualize o resultado do registro ao concluir a tarefa.

Registre somente metadados de modelo e effort efetivamente disponíveis. Se o identificador exato ou a configuração não estiverem expostos na sessão, escreva "não informado pela sessão"; não deduza esses valores pela complexidade do trabalho.

O escopo inicial solicitado é somente criar arquivos vazios/placeholders para um Sistema de Atendimento ao Cliente com PostgreSQL. A implementação deve aguardar uma solicitação posterior do usuário. `prompts.md` e este arquivo são documentação operacional para atender ao registro contínuo solicitado.
